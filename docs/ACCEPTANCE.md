# 驗收清單

將需求逐項對應到實作與自動化測試。所有測試在 CI（`.github/workflows/ci.yml`）每次推送時執行。

## 審查紀錄

- **程式碼審查**：10 項發現全部修正（對話長度上限、空白回覆、錯題本複習中斷、新紀錄判斷、小數填答、chunk 載入失敗處理等）。
- **安全審查**：KaTeX 未開啟 `trust`，AI 輸出無法執行腳本；API 金鑰只在伺服器端；匯入檔逐欄驗證。未發現高信心漏洞。
- **事實查核**：5 個查核 agent 逐科檢查題目答案、公式、史實、法規與課綱代碼，共修正約 55 處（例：原住民族 2026 年西拉雅族核定為第 17 族、轉形斷層方向、海水晒鹽原理、比例原則說明、引文原句）。

## 已知限制

- 教育部與國教院網站在開發環境無法直接開啟，課綱內容依官方 PDF 摘要、學校課程計畫與既有知識彙整；各版本教科書單元順序可能不同（網站已標註）。
- AI 功能需在 Vercel 設定 `ANTHROPIC_API_KEY` 後才會開啟；未設定時情境對話自動使用選項腳本模式。
- 限流為各 function 執行個體盡力計算，建議搭配 Anthropic Console 花費上限。
