# 1019課程版本：各出版商國高中課本目錄

`1019課程版本.xlsx` 統整翰林、康軒、南一（國中）與三民、龍騰、南一、全華、泰宇（高中）的課本目錄。
第一版共 494 冊，其中 72 冊查到目錄，其餘留空待補。

## 檔案

| 檔案 | 說明 |
|---|---|
| `1019課程版本.xlsx` | 產出的 Excel |
| `textbooks/*.json` | 蒐集到的原始資料，一個檔案一組（國中依出版商、高中依科目群） |
| `build_textbooks.py` | 把 JSON 統整成 Excel：`python3 data/build_textbooks.py` |

補資料時直接編輯或新增 `textbooks/*.json`，再重跑腳本。同一冊只要有任何一筆有章名，腳本就會自動移除該冊的「未查到」空白列，相同內容的重複列也會自動去除。

## 工作表

- **說明**：資料來源方式、限制、官網網域。
- **國中**、**高中**：一章一列（國文、英文為一課一列）。查不到的冊次保留一列，章節空白並以黃底標示。
- **涵蓋總覽**：每冊一列，「已查到章（課）數」以 COUNTIFS 公式從資料表計算。

## 欄位定義（JSON 與 Excel 相同）

| 欄位 | 填法 |
|---|---|
| 版本 | 出版商：翰林、康軒、南一、三民、龍騰、全華、泰宇 |
| 學段 | 國中／高中 |
| 年級 | 7–12 的數字；高中選修不確定開課年級就留空 |
| 冊次 | 國中填「上」「下」。高中照來源的冊名填，例如「第一冊」「3A」「甲上」「選修物理I」「選修歷史Ⅰ」 |
| 科目 | 國文、英文、數學、生物、理化、地球科學、歷史、地理、公民（國中）／公民與社會、物理、化學（高中） |
| 章 | 章或單元名稱，含章次，例如「第1章 整數的運算」；國文、英文放課名 |
| 節 | 該章各節，以全形分號「；」分隔；沒查到就留空 |
| 學年度 | 來源標示的學年度（115 為現行）。只找到舊學年度時照實填 114、113 等；來源沒標示就填「未標示」或留空 |
| 來源類型 | 出版商頁面、出版商官網、學校課程計畫、書店頁面、其他 |
| 來源網址 | 實際依據的網址 |
| 備註 | 必填情況：查不到時寫「未查到」並簡述原因；來源不是課本本身（如均一「類某版」課程、配套講義、學校計畫）；只看到搜尋摘要、沒開原頁；來源之間有出入；冊次歸屬是推定的（寫「待核對」） |

## 填寫規則

1. 只記錄來源中實際看到、且明確標示出版商的內容，不憑記憶補，也不推測。
2. 查不到的冊次也要留一筆：章、節為空字串，備註寫「未查到」。
3. 使用繁體中文。
4. 到出版商官網核對過的列，來源類型改為「出版商官網」，並更新學年度。

## 第一版的限制

第一版蒐集時，出版商官網在雲端環境中被網路政策阻擋，所以資料全部來自 WebSearch 的搜尋摘要，主要是學校課程計畫、均一課程頁與書店頁。每輪 200 次的搜尋額度用完後就停止了，社會、自然、英文多數沒搜到。
官網網域：翰林 hle.com.tw、康軒 knsh.com.tw（另有 digitalmaster.knsh.com.tw）、南一 nani.com.tw、三民 sanmin.com.tw、龍騰 **ltedu.com.tw**、全華 chwa.com.tw、泰宇 tyedu.com.tw（待確認）。翰林國文課次放在 sites.google.com/hanlin.com.tw。

## 各冊狀態

✅ = 已查到（括號內為章／課數），空白 = 未查到。
